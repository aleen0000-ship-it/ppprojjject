# Study Buddy

## Purpose
Study Buddy is a small Python app that helps students track study tasks.

## How to run
Run `buddy.py` with Python 3. No external packages are required.

## How to contribute
Open an issue for a focused change, create a branch from `main`, make a small commit, test the change, and open a pull request for review.

## Out of scope
This project does not include user accounts, cloud synchronization, notifications, or a graphical interface.
